# P5-2B solver-facing adapter validation

Structural dry-runs at 0 km and 10 km pass dimensions, IDs, finite values and the eight-arc distance override. However, P5-2B acceptance is BLOCKED: the frozen model has no per-arc transport-cost-rate member, and its transport formula uses a piecewise distance tariff (or raw distance), not the source 0.39 CNY/(tonne-km). The frozen Instance also exposes scalar k and hat_h, while the source provides transport and inventory emission coefficients. Injecting these source coefficients faithfully would require changing the frozen mathematical model or adding new model members, which is prohibited. The dry-run and smoke artifacts are retained but are not accepted as real-case results. No further smoke or formal run may start until this mapping is resolved by an explicit model-design decision.
