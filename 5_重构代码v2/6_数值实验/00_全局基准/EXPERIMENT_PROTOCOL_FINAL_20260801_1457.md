## 2. 随机种子格式修订

早期工作版协议分别设置了实例生成种子和GA运行种子。经冻结代码和并行预测试核查，当前实现仅提供一个`random_seed`字段，该字段同时控制：

- 合成实例生成；
- GA初始种群；
- GA选择、交叉和变异中的随机过程。

因此，正式协议不再使用两套种子，统一采用以下10个全局随机种子：

```text
101, 202, 303, 404, 505,
606, 707, 808, 909, 1010
```

说明：

1. 早期种子格式与当前代码接口不一致，但尚未用于正式10组实验，因此没有正式结果受到影响。
2. 第`r`组实验只使用一个`random_seed`。
3. 同一对照实验或敏感性分析的不同情景必须使用相同的10个种子。
4. 10次重复反映实例随机性和GA随机性的综合变化，不将两类随机性分别估计。
5. `MANIFEST.txt`和结果汇总表只记录`random_seed`，不再记录`instance_seed`和`ga_seed`。

## 4. 正式GA–BP全局配置

论文对外统一称为**GA–BP**。多列定价、认证结果缓存和外层适应度并行评价均作为GA–BP的内部实现组成部分，不另设“加速算法”名称，也不进行独立消融实验。

对偶平滑经多次测试没有产生有效改善，正式配置固定为0，论文不得声称实际启用了对偶平滑。

### 4.1 模型基准

- 碳交易价格：`carbon_price=2.0`
- 初始碳配额：`carbon_cap=100000`
- 投资成本系数：`delta=3000`
- 投资规模指数：`investment_exponent=0.5`
- 减排率范围：`[0,1]`
- 单个配送中心减排率编码：10位
- 投资成本在列利润中扣除：`use_invest_in_column=true`
- 使用需求规模平方根投资形式：`use_sqrt_investment=true`
- 基准服务水平：`0.975`
- 实际正态分位数：`z_alpha=1.96`

`delta=5000`不再作为全局基准，而是RQ2-1的候选敏感性水平之一。所有敏感性水平以最终实验矩阵为准。

### 4.2 GA参数

```yaml
population_size: 30
max_generation: 50
crossover_rate: 0.7
mutation_rate: -1
elitism: true
early_stop: true
convergence_generations: 10
convergence_tolerance: 0.001
parallel_fitness: true
num_threads: 8
```

`mutation_rate=-1`是代码的自动变异率标记，实际逐位变异率为总染色体长度的倒数。

8个GA工作进程由10×30有限预测试确定。串行、2、4和8进程的目标值、五代轨迹、BP调用数和缓存命中完全一致；8进程墙钟时间为10.67秒，串行为47.50秒，且未出现并发、内存或CPLEX许可错误。

### 4.3 BP与CPLEX参数

```yaml
pricing_algorithm: 0
pricing_max_cols_per_dc: 3
dual_smooth_alpha: 0
rc_eps: 1.0e-6
max_cg_iterations: 2000
max_branch_nodes: 10000
bp_time_limit_sec: 600
bp_relative_gap: 0
cg_early_stop: false
parallel_pricing: false
cplex_threads: 1
```

解释：

- `pricing_algorithm=0`表示简化候选价格生成并使用Algorithm 3进行精确验证；
- 每个配送中心每轮最多加入3个改进列；
- 对偶平滑关闭；
- 外层GA采用8进程并行，但每个BP内部的CPLEX保持单线程；
- 定价层不启用线程并行，避免与GA进程并行混用；
- 程序没有独立的完整GA内部墙钟限制，完整GA由最大代数、提前停止和每次BP的600秒限制控制；
- 服务器作业系统若设置外部wall-time，必须在`MANIFEST.txt`中记录。

## 6. 五部分实验结构

### Part 1：GA–BP算法验证与规模表现（RQ4）

1. 固定`w`下CPLEX与BP的正确性比较；
2. Grid Search–BP与GA–BP的解质量和计算效率比较；
3. GA–BP规模扩展实验。

### Part 2：减排投资的经济与环境价值（RQ1）

比较不允许减排投资和允许优化减排投资时的利润、排放、投资成本、碳交易及网络结构。

### Part 3：减排投资成本特征的影响（RQ2）

- RQ2-1：投资成本系数`delta`的影响；
- RQ2-2：投资规模经济参数`gamma`的影响。

### Part 4：碳政策参数的影响（RQ3）

- RQ3-1：碳交易价格的影响；
- RQ3-2：初始碳配额的影响。

### Part 5：公开数据驱动的现实案例

现实案例使用固定现实网络，不适用10组随机实例规则。必须区分：

- 真实公开数据；
- 代理数据；
- 文献校准参数；
- 研究者设定参数。

## 7. 结果统计规则

10组实验原则上报告：

- 均值；
- 标准差；
- 最小值；
- 最大值；
- 完成率或认证率。

成对情景优先先计算每个种子的相对变化，再汇总：

\[
\Delta_r=
\frac{Y_r^{(1)}-Y_r^{(0)}}{|Y_r^{(0)}|}\times100\%.
\]

只有存在CPLEX或完整Grid Search确定性最优基准时，才能使用“optimality gap”。没有已知全局最优值的大规模实例，只能报告完成状态、认证比例或相对best-known solution的偏差，不得称为最优性gap。

## 8. 求解状态与异常处理

正式有效结果必须：

- 存在可行整数解；
- 状态和停止原因明确；
- gap及未处理节点数被记录；
- 不存在未说明的求解器错误。

下列状态必须单独报告，不能自动当作最优结果：

- `TIME_LIMIT`
- `NODE_LIMIT`
- `CG_ITERATION_LIMIT`
- `SOLVER_ERROR`
- `RMP_NOT_OPTIMAL`
- 其他异常终止状态

发生超时或异常时，保留原始日志和结果目录，不得删除或用其他种子替换。论文汇总应报告完成率和异常实例数量。
