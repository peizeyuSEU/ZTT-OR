# 当前算法与实验口径

> 本文以当前代码、回归测试和 2026-07-30 之后的实验为准。根目录 `PROJECT.md`
> 与早期架构文档用于记录重构背景，其中部分算法描述已经过时。

## 1. 最终算法定位

- 整体方法：`Hybrid GA–BP matheuristic`。
- 外层 GA：搜索连续减排率向量 `w`，不保证对 `w` 的全局最优。
- 内层 BP：固定 `w` 后求解离散选址—分配—定价问题。
- 只有固定 `w` 的 BP 完成全部严格列生成和分支定界时，才报告
  `OPTIMAL_CERTIFIED`。
- GA 的最终结果统一报告 `HEURISTIC_BEST_FOUND`；最终个体的 BP 认证状态、
  上界和 gap 单独使用 `inner_bp_*` 字段记录。

## 2. 当前求解链路

1. GA 将每个 DC 的减排率编码为二进制染色体。
2. 给定一个 `w`，Branch-and-Price 求解内层问题。
3. 每个 B&B 节点用严格列生成求 LP 松弛。
4. 一列表示 `(DC j, 服务集合 S, 统一价格 p_j)`。
5. 候选价格来自零售商保留价；右分支强制服务时，价格不得超过所有强制零售商
   最低保留价。
6. 定价 oracle 对每个 DC、每个候选价格求最优服务集合。
7. 当前正式精确定价使用论文 Algorithm 3，即 `pricing_algorithm=1`。
8. 分支对象是聚合分配变量 `x_ij`，不是早期文档所写的列变量 `Z_(j,S)`。

## 3. 完整列利润

RMP 和定价必须使用同一个完整列利润。减排投资成本已经进入列系数：

`I_j(w_j,D_j) = 0.5 * delta * w_j^2 * D_j^gamma`

其中 `0 < gamma <= 1`，基准为 `gamma=0.5`。由于 `D_j` 依赖服务集合，正式模型
不得在服务集合选定后再统一扣除投资成本。`use_invest_in_column=true` 是当前正确
口径；旧的事后扣除路径仅保留历史回归用途。

## 4. 精确性与加速边界

不损害固定 `w` 最优性认证的措施包括：

- 定价 DC 级并行；
- 完全相同 `w` 的精确适应度缓存；
- 缓存列仅作为当前定价 incumbent；
- Algorithm 3 内部等价计算、bitmask 去重和重复候选消除；
- K>1 时附加正检验数列，但完整定价仍必须返回全局最佳列；
- restricted-MIP 只用于寻找整数下界，不替代严格节点 LP。

以下情况不能报告认证最优：

- BP 时间或节点限制触发；
- 相对 gap 限制提前终止；
- 任一节点列生成未完成；
- 没有取得整数可行解；
- 仅有外层 GA 的 best-found 结果。

## 5. 当前正式实验要求

每次正式实验至少保存：

- 实例规模、seed、delta、gamma；
- 定价算法、每 DC 最大加列数；
- 配置变异率、有效逐位变异率及是否实际启用；
- 总体 outcome 与内层 BP 状态；
- best feasible、内层上界和内层 gap；
- 碳排放、配额、e+、e-、净碳交易成本；
- 投资成本、开放 DC、服务零售商；
- 节点数、CG 轮数、生成列数；
- GA/BP/CG/PS/CPLEX/BB 时间；
- 最终 `w`。

单次运行生成 `result.csv`，批量实验生成 `summary.csv`。没有整数可行解时，
利润、排放和网络方案字段必须留空，不能用 0 或根节点 LP 冒充。

## 6. 已确认风险与后续优先级

1. Algorithm 3 仍是大规模实例的主要耗时，占困难实例约 86%–99%。
2. 高 `w` 会显著增加候选复杂度和 CG 退化；耗时不能只按 DC/零售商数量外推。
3. 并行 GA 当前每个个体创建独立 BP 子进程，父进程尚未跨代缓存重复染色体；
   精英和重复个体可能被重复求解。这是下一项安全加速候选。
4. 应增加 GA 的适应度请求数、唯一 `w` 数和缓存命中数，解释不同变异率为何改变
   时间和搜索覆盖度。
5. `1/L` 是当前稳健默认变异率，但正式参数结论仍需更长代数、更多 seed 和较大规模
   的配对敏感性实验支持。
6. `Simplified` 已存在随机穷举反例，不能作为普遍精确定价 oracle；正式认证依赖
   Algorithm 3 的理论推导与持续穷举回归。

## 7. 最低回归门槛

修改目标函数、定价、分支约束或结果认证后，至少必须：

1. 运行投资成本与状态分类测试；
2. 运行 225 个 `n=4..12` 的确定性随机穷举定价回归；
3. 对固定基线比较目标值、状态、节点、CG 轮数和列数；
4. 性能优化必须同时报告修改前后 PS 与总时间；
5. 未通过上述验证的实验原型不得进入正式默认配置。
