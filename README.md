# 碳限额与交易政策下供应链网络设计优化

遗传算法 + 分支定价（GA+BP）求解器。

## 快速开始

```bash
cd 4_重构代码
make              # 编译单次运行
make experiments  # 编译批量实验
make run          # 单次运行（使用 config.yaml）
make table4_1     # 运行表4.1（不同规模）
make table4_2     # 运行表4.2（delta灵敏度）
make verify       # 运行验证
```
