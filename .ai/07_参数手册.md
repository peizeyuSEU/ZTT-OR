# 参数手册 — 所有可配置参数

## 参数配置方式

所有参数通过 **YAML 文件** 配置，支持三种场景：

| 场景 | 配置文件 | 运行命令 |
|:---|:---|:---|
| **单次运行** | `4_重构代码/config.yaml` | `make run` |
| **批量实验** | `src/0_experiments/table4_1.yaml` | `make table4_1` |
| **命令行指定** | 任意 YAML 文件 | `../bin/run my_experiment.yaml` |

### 覆盖规则

在批量实验中，YAML 文件顶部的参数为**全局默认值**，`experiments:` 列表中的每个条目可独立覆盖任意参数：

```yaml
# 全局默认
population_size: 30
max_generation: 50

experiments:
  - name: "custom"
    population_size: 50    # 只覆盖这个条目
    # max_generation 仍用 50
```

## 实验条目可覆盖字段

在批量实验中，每个 `experiments` 条目可以覆盖**上述任意参数**。示例：

```yaml
experiments:
  - name: "custom_test"
    num_dc: 5
    num_retailers: 20
    population_size: 50
    max_generation: 100
    delta: 3000
    random_seed: 12345
    carbon_price: 5.0
    holding_cost: 15.0
    use_sqrt_investment: false
    use_paper_algorithm3: true
    verbose: true
```

所有未在条目中指定的参数，自动继承 YAML 文件顶部的全局默认值。
