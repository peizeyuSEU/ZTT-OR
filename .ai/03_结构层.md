
## 依赖关系

### 文件间 #include 关系（目标）

```
第1层 launcher/
  → Config.h, DataGenerator.h, 第4层各算法, 第5层各文件

第4层 algorithm/
  → Instance.h, Config.h
  → formula/08_Objective.h（调公式）
  → base/ 各工具

第3层 formula/
  → core/Instance.h（只读数据）
  → 不依赖其他层

第5层 postprocessor/
  → formula/09_PostCompute.h
  → core/Solution.h

基础层 base/
  → 不依赖任何业务模块
```

### 核心设计约束

- **第3层不依赖第4层**（公式独立于算法）
- **第4层只调第3层**（算法不自行计算公式）
- **第5层只调第3层的09_PostCompute**（后处理只做反算）
- **第0/1/2层是编排层**，不包含业务逻辑
