## 核心问题

碳限额与交易政策下，企业同时决策：
1. **选址** — 在哪建配送中心（DC）
2. **分配** — 哪些零售商分配给哪个DC
3. **定价** — 每个DC定什么批发价（通过价格筛选有利可图的零售商）
4. **库存** — 每个DC的订货量 Q_j（EOQ公式消掉）
5. **碳交易** — 买/卖多少碳配额（e+, e-）
6. **减排投资** — 每个DC的减排率 w_j ∈ [0,1]

目标：**利润最大化**

## CAT-SCND 数学模型

### 原始模型 Model-Πκ（论文式3.54-3.58）

目标函数：
```
max Σ_j[ Σ_i r_i(p_j)μ_iY_ij - f_jX_j - ½δw²_j√(Σ_iμ_iY_ij)
    - ((F_j+g_j)/Q_j + c(a_j) + c(d_ij))Σ_iμ_iY_ij
    - hQ_j/2 - hz_α√(L_jΣ_iσ²_iY_ij) ] - p̂(e⁺-e⁻)
```

约束：
- 碳约束：总碳排放(1-w_j) + (e⁻-e⁺) = C
- 每个零售商最多由一个DC服务
- Y_ij ≤ X_j（只有开设的DC能服务）
- 0 ≤ w_j ≤ 1, X_j,Y_ij ∈ {0,1}

### 重写后的模型 Model-Πχ（论文式3.62-3.69）

通过EOQ公式消掉Q_j，通过碳约束消掉e+,e-：
```
max Σ_j[ Σ_i r_i(p_j)μ_iY_ij - (f_j + p̂f̂_j(1-w_j))X_j
    - Σ_i(c(d_ij) + p̂b̂_ij(1-w_j))μ_iY_ij
    - ½δw²_j√(Σ_iμ_iY_ij)
    - (h + p̂ĥ(1-w_j))z_α√(L_jΣ_iσ²_iY_ij)
    - √(2(F_j+g_j)(h + p̂ĥ(1-w_j))Σ_iμ_iY_ij)
    - (c(a_j) + p̂b̂_j(1-w_j))Σ_iμ_iY_ij ] + p̂C
```

### 集合覆盖模型 Model-ΠM（论文式4.3-4.6）

对固定 w_j：
```
max Σ_jΣ_{S⊆I} R̄_{j,S} Z̄_{j,S} + p̂C
s.t. Σ_jΣ_{S: i∈S} Z̄_{j,S} ≤ 1, ∀i
     Σ_{S⊆I} Z̄_{j,S} ≤ 1, ∀j
     Z̄_{j,S} ∈ {0,1}
```

其中 R̄_{j,S} 为DC j服务集合S的净收益：
```
R̄_{j,S} = Σ_i r_i(p_j)μ_i - (f_j + p̂f̂_j(1-w_j))
         - Σ_i(c(d_ij) + p̂b̂_ij(1-w_j))μ_i
         - ½δw²_j√(Σ_iμ_i)
         - (h + p̂ĥ(1-w_j))z_α√(L_jΣ_iσ²_i)
         - √(2(F_j+g_j)(h + p̂ĥ(1-w_j))Σ_iμ_i)
         - (c(a_j) + p̂b̂_j(1-w_j))Σ_iμ_i
```

## 四层求解框架

| 层级 | 作用 | 方法 | 对应代码 |
|:---|:---|:---|:---|
| 第1层 | 消掉库存变量 | EOQ公式 Q_j* = √(2(F_j+g_j)D_j / (h + p̂ĥ(1-w_j))) | Objective.h |
| 第2层 | 求解LP松弛 | **列生成**（含定价子问题，参数线性规划 O(n³)） | ColumnGeneration.h → PricingSolver.h |
| 第3层 | 修复整数性 | **分支定界**（DFS，对分数 Z_{j,S} 分支为0或1） | BranchAndBound.h |
| 第4层 | 搜索 w_j | **遗传算法**（二进制编码10位，精英保留，轮盘赌） | GeneticAlgorithm.h |

### 完整求解链
```
遗传算法(GA) → 搜索w_j
  ↓ 对每个个体(一组w_j)
  分支定价(BP) → 固定w_j求解整数规划
    ↓
    列生成(CG) → 求解LP松弛
      ↓
      定价子问题(PS) → 找使检验数最大的(j,S,p_j)
    ↓
    分支定界(BB) → 修复整数性
```

## 深度洞察（2026-07 本轮建模正确性审视）

### 洞察1：投资成本解耦是「精确」而非「近似」

**现象**：投资成本 `½δw²_j√D_j` 含 √D_j（对需求量凹），被排除在 `Objective::columnProfit` 之外；
`BranchAndPrice::solve()` 在 BB 求出整数解后，才对每个开启的 DC 按其**被选中那一列**的 D_j 事后补扣投资成本。

**一度的疑虑**：√D_j 使投资成本对需求非线性、凹，看似会破坏「列利润可加分解」的列生成前提。

**澄清（对照 Model-ΠM 式4.3-4.6）**：
- 投资成本是**列内量**——对固定的 w_j 和固定的服务集合 S，`D_j = Σ_{i∈S} μ_i` 是常数，`½δw²√(Σμ)` 也是常数，天然属于该列的净收益 R̄_{j,S}。
- 约束「每个 DC 至多选一列」`Σ_S Z̄_{j,S} ≤ 1` 保证整数解里**每个 DC 只对应一列**（一个确定的 S）。因此「事后按最优解那一列的 D_j 补扣」 ≡ 「把投资成本算进该列的 R̄_{j,S} 里」——两者数值完全相同。
- 依赖的契约：整数解每 DC 单列（即 `optimal_S` 提供完整 R 维选中集合）。这在 BB 修复整数性后天然成立。

**结论**：解耦利用了模型结构（列内常数 + 单列约束），是正确简化，**不引入任何近似误差**。

### 洞察2：定价优化（A/B/D）无损的模型层根源

投资成本本就不在列利润里 → 定价子问题的检验数（reduced cost）只涉及列利润的线性项（收入-固定-运输-库存）。
优化 D（增量式 RC 计算）只重写这条**线性项**的累加方式，与投资成本项**天然正交**，故解完全不变（已由并行策略对比 4 方案对照验证：利润 2175429.20 全一致）。

### 洞察3：GA+BP 两层路径放大器（定价精确性 ≠ 整数解最优性）

定价子问题的「精确程度」并不单调决定最终整数解利润。GA(搜 w) 与 BP(列池路径) 两层非凸搜索会放大定价扰动：
Simplified(0) 反而利润最优、Algorithm3(1) 精确却把列池带偏、ConvexHull(2) 最快但丢内部点对候选收敛到少一个 DC。这解释了「利润 0>1>2」的反直觉现象。

### 洞察4：实验「碳排不同却同利润」现象已定性——多重最优解（退化），减排确实生效

**已核实（读各实验目录 report.txt 的 DC 详情，2026-07-23）**：A/C 组与 B/D 组

- **最优 w 向量完全相同**：w1=0.34, w2=0.34, w3=0.42, w4=0.10, w5=0.47, w7=0.49, w9=0.43（开启的 7 个 DC），批发价 p 也几乎一致。
- **差异仅在若干 DC 的服务总需求 D_j 分布**：如 A/C 的 DC4 服务 D=5291、DC5 D=17305、DC7 D=25911、DC9 D=5946；B/D 的 DC4 D=2651、DC5 D=14635、DC7 D=28551、DC9 D=8616。总服务需求相同，但零售商在几个 DC 间的**归属不同**。

**结论**：
1. **不是 bug**，而是**多重（退化）最优解**——同一组 w 下存在多个等利润的零售商分配方案。GA 串行(A/C)与并行(B/D)因个体评估顺序不同，最终落在不同的等价最优分配上，故 D_j 分布不同 → 碳排不同（292877 vs 279428），但**总利润完全相同 2175429.20**。
2. **减排确实生效**：w 普遍在 0.34~0.49（非全零），此前「疑似未开 DC 的 w 差异」的猜测被推翻，真相是**开启 DC 的分配退化**。
3. `canonicalW`（未开 DC 归零）只影响缓存 key，不影响此现象。

**输出层面的收获**：report.txt **已完整落盘**每个开启 DC 的 w/p/D/Q* 与碳交易 E/e±/净成本，可直接核实——但 **PostProcessor::print() 从未被调用**、终端摘要与 summary.txt **未展示碳交易与逐 DC 的 w/D**（方向2改进点：把这些关键量提升到终端摘要与批量对比表）。

## 定价子问题三方案对比与选型（2026-07）

### 三方案定义（config.yaml 的 pricing_algorithm）

| 值 | 方案 | 说明 |
|:---|:---|:---|
| **0** | **Simplified（简化枚举，选定基线）** | 简化坐标 (xi,yi)=(-μi/Ai,-σ²i/Ai)，每对点分 above/below 共 2 候选，n² 全点对枚举 |
| 1 | Algorithm3（论文精确） | 累积坐标，余弦相似度分 I1/I2/I3 生成 12 候选，理论完备但大规模枚举爆炸 |
| 2 | ConvexHull（凸包剪枝，优化4） | Andrew 单调链求凸包，只枚举凸包相邻边 O(n) 条线做半平面切割 |

### 核心结论

- **利润 0 > 1 > 2（反直觉）**：定价精确性 ≠ 整数解最优性。GA+BP 两层路径放大器主导，Simplified 走运命中更优路径；论文精确定价反把列池路径带偏。
- **速度 2 < 0 < 1**：ConvexHull 比 Simplified 快 3 倍、比 Algorithm3 快 8.6 倍（优化4 加速达成），代价是丢内部点对候选 → 收敛到 6-DC 少一个 → 利润低 0.67%。
- **Algorithm3 最慢且利润不占优**，性价比最差。
